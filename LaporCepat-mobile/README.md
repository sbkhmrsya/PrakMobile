# LaporCepat (tampilan depan)

Aplikasi Expo (TypeScript + Expo Router). Hanya menampilkan halaman depan.

```bash
npm install
npx expo start
```

Struktur: `app/` (halaman), `components/`, `constants/` (array of objects), `functions/` (custom function), `styles/` (external styles), `types/`.
Jawaban pertanyaan & catatan modifikasi ada di `JAWABAN.md`.
